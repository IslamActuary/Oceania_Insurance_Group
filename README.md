## Motor Sector Analysis

**Goal:** Analyze 10,000 motor insurance policies to support 
pricing and reserving decisions.

**Tools:** R · dplyr · ggplot2 · fitdistrplus · actuar

**Key Results:**
- Luxury vehicles: highest max claim — 521,987 SAR
- Log-normal distribution confirmed best fit (AIC = 196,522)
- Average claim by vehicle type analyzed using group_by + summarise
